# การพยากรณ์ยอดเงินสดจ่ายล่วงหน้าหนึ่งวันของสาขาธนาคาร

Repository นี้จัดทำจากโครงการ Independent Study เรื่องการพัฒนาและเปรียบเทียบแบบจำลอง
Machine Learning สำหรับพยากรณ์ยอดเงินสดจ่ายรวมของสาขาธนาคารในวันถัดไป

ข้อมูลที่ใช้ครอบคลุมช่วงเดือนมกราคม 2018 ถึงเดือนธันวาคม 2020 จำนวน 10 สาขา
หลังเตรียมข้อมูลและสร้างตัวแปรแล้ว มีข้อมูลสำหรับสร้างแบบจำลอง 10,532 branch-day observations

## แนวทางหลัก

```text
ข้อมูลดิบ
 -> ตรวจคุณภาพข้อมูล
 -> ตรวจวันที่ของแต่ละสาขาที่หาย
 -> สร้าง Target วัน t+1
 -> สร้าง Calendar / Lag / Rolling Features
 -> แบ่ง Subtrain / Validation / Final Test ตามเวลา
 -> เปรียบเทียบ Baseline และ Machine Learning
 -> Residual Modeling
 -> ประเมิน Final Test
 -> จำลอง Safety Buffer
```

## โมเดลสุดท้าย

ใช้ Rolling7 เป็นค่าพยากรณ์ตั้งต้น และใช้ HistGradientBoosting พยากรณ์ Residual
พร้อม Residual Clipping ที่เปอร์เซ็นไทล์ 1 และ 99

## ผล Final Test

- WAPE ของ Final Model: **54.67%**
- WAPE ของ Rolling7: **71.15%**
- MAE: **1,354,264.22 บาท**
- RMSE: **2,847,928.10 บาท**

เมื่อไม่เพิ่ม Safety Buffer อัตรา Under-coverage เท่ากับ 39.44%
และเมื่อเพิ่ม Buffer เป็น 30% อัตราดังกล่าวลดลงเหลือ 27.76%
แต่ Over-coverage เพิ่มขึ้นจาก 52.99% เป็น 64.67%

## หมายเหตุเรื่องข้อมูล

Repository สาธารณะนี้ไม่ใส่ข้อมูลธนาคารจริง และล้าง Output ใน Notebook ออกแล้ว
เพื่อไม่ให้ค่าธุรกรรมจริงหรือข้อมูลระดับ branch-day ถูกเผยแพร่
